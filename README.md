# Life Agent

Working name. A personal life agent you share with friends.

It tracks your work, habits, streaks, sleep and diet. A tough-love coach checks in every day and calls you out when you slack. Add friends, share only the stats you choose, and set a shared goal, like 100 pushups a day or losing 5 kg. Every night the coaches post a banter recap to the group.

## Status

Planning. No code yet.

## Decided so far

- An installable web app (PWA) for iPhone, Android and Mac. No native apps.
- The first version has personal tracking and friends' challenge rooms.
- A free beta comes first. Paid plans come later.
- Each person picks which stats their friends can see. The nightly recap is built from those stats and nothing else.
- The coach reaches you through phone notifications.

## The coach's limits

The coach is hard on effort and never on bodies or food. It stops the tough act when someone sounds distressed.
